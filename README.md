# 🛒 SoukExpress - منصة التوصيل السريع

<div dir="rtl">

منصة توصيل مغربية تربط بين **الزبون**، **التاجر**، و**الموصل** — مصممة خصيصاً لمدينة **أكادير**.

## ✨ المميزات

- 🛍️ **للزبون**: تسوق من المتاجر المحلية، تتبع الطلبات، تقييم المتاجر
- 🏪 **للتاجر**: إدارة المتجر، إضافة المنتجات، متابعة الطلبات، إحصائيات كاملة
- 🚚 **للموصل**: استقبال الطلبات، التوصيل، متابعة الأرباح والعمولات

## 🚀 المميزات التقنية

- 🌙 الوضع الليلي (Dark Mode)
- 📲 PWA - قابل للتثبيت على الهاتف
- 🔔 إشعارات صوتية للطلبات الجديدة
- 📱 واجهة عربية RTL متجاوبة
- ⚡ الوقت الحقيقي عبر Supabase
- 💬 دعم فني عبر واتساب

## 🛠️ التقنيات المستخدمة

- **HTML5 + CSS3 + JavaScript**
- **Supabase** (قاعدة البيانات)
- **PWA** (Service Worker + Manifest)
- **GitHub Pages** (الاستضافة)
